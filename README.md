Capstone Final Project: Music Genre Classification & Analytics

📋 Project Overview
This repository contains the code, data analysis, and final documentation for my capstone data analytics project. The project explores a dataset of over 7,700 music tracks, performing rigorous data cleaning, exploratory data analysis (EDA), and audio feature correlations to uncover insights into track characteristics.

 📂 Repository Contents
 **`Music_Genre_Classification_Analytics.ipynb`**: The primary Google Colab Jupyter Notebook containing data wrangling, feature engineering, missing value imputation, and visual distribution charts.
 **`MAIN PROJECT REPORT.pdf`**: The comprehensive final project report detailing analytical methodology, findings, and conclusions.

## 🛠️ Tools & Technologies Used
* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **Google Colab** / Jupyter Notebooks
* **Data Analytics Frameworks** (Data cleaning, median imputation, outlier analysis)

📊 Key Steps Performed
1. **Data Cleaning:** Handled invalid track durations, standardized string entries, and removed structural duplicates.
2. **Missing Value Imputation:** Imputed missing numerical features using robust median metrics.
3. **Exploratory Data Analysis:** Generated specialized distribution charts and correlation matrices to analyze audio track attributes.
